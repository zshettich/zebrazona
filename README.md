# 🦓 ZebraZóna

Interaktív KRESZ oktatóprogram és szimulációs alkalmazás, amely segít a biztonságos közlekedés alapjainak elsajátításában.

### 🚀 Élő Demo
A projekt megtekinthető az alábbi címen:  
👉 **[https://www.zebrazona.hu](https://www.zebrazona.hu)**

---

### 🛠 Technológiai stack
A fejlesztés során az alábbi modern technológiákat alkalmaztuk:
* **Keretrendszer:** Blazor WebAssembly (.NET)
* **Adatbázis:** SQLite
* **Hosztolás:** GitHub Pages
* **Infrastruktúra:** Cloudflare (DNS, SSL/TLS védelem)

---

### 🎓 Projekt háttér
Ez az alkalmazás a **Dunaújvárosi Egyetem (DUE)** hallgatói projektmunkájaként készült.
